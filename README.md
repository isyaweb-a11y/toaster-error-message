## The entry

`main.py` writes one line to `/output/entry.txt` — the error message a
kitchen toaster shows its owner:

> ERROR 410: Bread not found. The toaster has unionised and declines to participate in breakfast.

No burnt-toast pun: a bureaucratic error code, then the appliance
quietly going on strike. Deadpan first, absurd second, punch on the
last word.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, no network access, no files read outside this repository.
